# NovaDrive Backend

NovaDrive is a backend platform for autonomous taxi operations, built with .NET 10 and ASP.NET Core Minimal API.

The project combines the requirements of a university backend assignment with a production-minded approach to structure, maintainability, testing, and incremental feature growth.


## Current Stack

- .NET 10
- C# 14
- ASP.NET Core Minimal API
- PostgreSQL
- MongoDB
- FluentValidation
- JWT authentication and role-based authorization
- Docker Compose
- xUnit integration test setup
